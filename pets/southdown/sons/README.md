# Les sons de l'agnelle Southdown

Tous ces fichiers sont repris **sans modification** de `pets/lainou/sons/`.
Leurs sources sont déjà créditées dans le [CREDITS du dépôt](../../../CREDITS.md).
Aucun nouvel enregistrement n'est ajouté, aucune cloche n'est reprise.

- `agneau-1.mp3` : une coupe de `Baa.ogg`, le bêlement d'agneau du
  *Baby Animals Sounds Pack* de
  Technopeasant ([OpenGameArt](https://opengameart.org/content/baby-animals-sounds-pack)),
  publié sous **CC0 1.0**. C'est la seule prise de cette voix dans le dépôt ;
  le moteur ouvre la bouche pendant l'appel (`mouth = true`).
- `broute-1.mp3`, `broute-2.mp3` : broutage et mastication de foin, enregistrés
  par Joseph SARDIN ([BigSoundBank](https://bigsoundbank.com), sources
  n° 0990 et 0497), **CC0 1.0**.
- `pose-1.mp3`, `pose-2.mp3` : sauts dans l'herbe, même auteur et licence,
  sources n° 1839 et 1840.

Les quatre autres fichiers `agneau-2.mp3` à `agneau-5.mp3` de Lainou sont
écartés : ce sont les prises de chevreaux n° 1377 à 1379 de BigSoundBank
(les numéros sont encore dans les métadonnées MP3). La voix retenue est
bien celle de l'agneau déjà créditée séparément dans le dépôt : la forme
d'onde décodée de `agneau-1.mp3` correspond à celle de `Baa.ogg` (corrélation
0,990, après le décalage de coupe de 95 ms). Le pack consulté pour cette
vérification est resté hors du dépôt. La race et l'âge de cet agneau ne sont
pas documentés par la source.
